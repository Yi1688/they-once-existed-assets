# They Once Existed — Game Assets

《它们曾存在》Twine 游戏素材：53 张图片及 6 个音频文件。

图片位于 images/，音频位于 audio/。带内容版本号的直链分别见 image-urls.json 和 audio-urls.json。

原画署名见 images/未命名作品 44_副本3.jpg。音频按提供的原文件保留。本仓库不额外授予素材使用许可。

## 新游戏：《它们曾存在 · 神明的赠礼》

完整游戏保存在 [新游戏](新游戏/) 文件夹中，包含 HTML、Twine 源文件、全部现有图片与音频、原始剧本及制作源码。三位动物角色各有两个结局，共六个；猫分别为治疗后回家与告别。选角和手记统一黑白主题，猪鸭路线为黑底，猫路线为纯白底。

下载 `新游戏/新游戏.html` 后用浏览器打开即可游玩。图片与现有音频通过 GitHub 原始文件直链加载，HTML 可以单独移动或分享，游玩时需要联网并能访问 GitHub 原始文件服务。GitHub 文件页面显示 HTML 源码，需要下载后在浏览器中打开。

三位角色各有五段章节音频，共十五段，另有三种动物叫声，均使用 GitHub 原始文件直链。猫与鸭子新增的十段音频已按剧情场景接入。

重新构建需要 Python 3 和 Pillow：安装 `Pillow` 后运行 `python 新游戏/制作/build.py`。Harlowe 3.3.9 格式文件已包含在制作目录中。
构建时保留本地图片，用于读取尺寸和生成剪影；生成的 HTML 与 Twee 均使用 GitHub 直链。新增或替换素材后，请同步上传到仓库的「新游戏」目录。
