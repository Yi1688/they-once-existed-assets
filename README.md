# They Once Existed — Game Assets

《它们曾存在》Twine 游戏素材：53 张图片及 6 个音频文件。

图片位于 images/，音频位于 audio/。带内容版本号的直链分别见 image-urls.json 和 audio-urls.json。

原画署名见 images/未命名作品 44_副本3.jpg。音频按提供的原文件保留。本仓库不额外授予素材使用许可。

## 新游戏：《它们曾存在 · 神明的赠礼》

完整游戏保存在 [新游戏](新游戏/) 文件夹中，包含 HTML、Twine 源文件、全部现有图片与音频、原始剧本及制作源码。三位动物角色共有九个结局。

下载本仓库的 ZIP 并完整解压，打开 `新游戏/新游戏.html` 即可游玩。图片与音频使用相对路径，离线也能运行；分享时请保留整个「新游戏」文件夹。GitHub 文件页面显示 HTML 源码，需要下载后在浏览器中打开。

- [游戏 HTML](新游戏/新游戏.html)
- [Twine / Twee 源文件](新游戏/新游戏.twee)
- [使用说明](新游戏/使用说明.txt)
- [制作源码](新游戏/制作/)
- [分支与结局说明（含剧透）](新游戏/制作/分支说明.md)
- [Harlowe 宏与动态效果](新游戏/制作/动态效果与宏.md)

现有音频包括五段野猪章节音频和三种动物叫声。猫与鸭子暂无章节配乐或配音，仍可完整游玩。

重新构建需要 Python 3 和 Pillow：安装 `Pillow` 后运行 `python 新游戏/制作/build.py`。Harlowe 3.3.9 格式文件已包含在制作目录中。
