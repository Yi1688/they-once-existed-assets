# 分支与结局（含剧透）

扩展版共有 104 个可见页面，比原版增加 61 段剧情。三个角色各有两个结局，共六个。首次每个角色走到一个结局、连续体验三条故事，按正常阅读与探索估算约 10–15 分钟。重玩其它选择或收集全部结局需要更久。没有新增找同伴的第三结局。

默认起点为独立的「开始」页，从「开始游戏」进入选角，也可直接查看旅程手记。首页以三座黑白拱门对应森林、家与祭坛，支持悬停对白和叫声试听。页眉可随时返回首页。
野猪结局可直接进入猫的故事，猫结局可直接进入鸭子的故事，方便首轮顺序游玩三条路线。

## 野猪

单次经过 20–25 个剧情页，共有 31 个不同场景。

- 在遇到机器前，先发现溪水变浅；可以调查泥岸或埋在泥里的果子，再从土坡观察，选择停听或靠近。
- 找到小径后可以留下枯枝路标；倒树处可以找过去避雨的树洞，或查看机器没有吃掉的树干。闻过机油，还会看到铁壳里的人影。
- 认出巨神后可以叫它、等它回答，也可以低头等候。白雾散去后，可以尝木屑或追着阴影休息。黄昏时再选择认回程的路或继续等。
- 尝过木屑，会在最后抉择前明确想起它不能当食物。此前发现的树洞、来路和水源，也会出现在中后段的回忆中。
- 遇见机器后，可以直接靠近，也可以沿林缘查看小径。记住小径后，最后选择和存活结局会提到这条来路。
- 灯光照来时，可以直接撞击，也可以先闻味道。闻过味道，最后会想起机器没有呼吸。
- 撞击五次后，画面显出野猪神明的形状。长按约两秒，观察巨神喷出的白雾。
- 离开：回到林子，找到溪水和野果，活了下来。
- 留下：一直追随机器，树被砍完后机器离开，野猪因失去食物和水源而倒下。

## 猫

单次经过 21–29 个剧情页，共有 36 个不同场景。

- 开场可听隔壁猫说话，也可找不漏风的地方；之后听见门外的交谈，再选择靠近那只手或查看走道。
- 观察标签后可见来人拍照、保存凭据；推开食碗也可能让来人看见胶囊。这些细节会影响就医电话与告别后续。
- 吃饭和灰转彩后，增加提笼中的路程。可抬头看外面，也可藏进布下面；到家后发现门一直开着，可以慢慢走出来。
- 新家里增加喝不到水、打电话、叫一声或抓住袖口、出门去医院的过程。叫过之后，祭司段落会认出身边人的声音。
- 在医院醒来的分支增加探望，可尝试吃一点或再休息。告别分支增加叠好垫布、带空提笼回家的后续。
- 来人带猫回家之前，可以观察换标签的动作。记住标签后，新家段落会多出一处对照。
- 可以直接吃饭，也可以闻味道、拨开食物、推开碗。推碗后仍回到吃饭主线，不再解锁第三个救助结局。
- 新家可点击沙发和画像，也可走到窗边，看到领养人发现异常、准备联系医院。
- 祭司出现在昏睡的梦里。两个选项分别是「前往 · 回到人声里」和「放弃 · 我太累了」。
- 前往：在医院醒来，接受治疗；病情稳定后出院回家。医院醒来阶段使用猫幻想音频，最终结局使用上作收尾曲。
- 放弃：梦中跟着影子离开，现实中的抢救没能留住猫。领养人保留病历并举报卖家。告别阶段使用猫死亡音频，最终结局使用上作收尾曲。
- 猫的遭遇和举报后续均为故事情节，不作为现实新闻呈现。

## 鸭子

单次经过 23–25 个剧情页，共有 34 个不同场景。

- 开场可沿围栏找水，也可观察水里的光圈；遇到老鸭后，可以问被带走的鸭子有没有回来，也可以先问食物。
- 开门时可以查看脚印，或盯着撒粮的手。扶起鸭子的分支补充它为何陷在泥里。
- 争食后可以看看低处没能站起来的鸭子，也可以先护粮；留意倒下的鸭子会改变分粮前的对白。
- 被提起来后可查看木箱或听人声。称重后可以回想六粒粮或围栏，分享与否、是否去过围栏会改变回忆。
- 「是」「否」各增加一段祭司的回应，再进入原有的两个最终资料结局。
- 争食前可直接抢粮，或先扶起被挤倒的鸭子。
- 交替点击两只鸭子六次后，可自己吃完，也可分出一半。是否扶起鸭子影响分粮前的文字，分粮与否影响称重段落。
- 最后只保留「是」「否」，回答祭司关于造物主的提问。两种回答分别进入数据或日常行动资料页。

## 主题、布局和存档

开始界面、选角、手记使用黑白配色，野猪和鸭子的角色卡为黑底，猫的角色卡为白底。猪鸭整段剧情及结尾为黑底浅字，猫为纯白底深字。原画保留原色，剧情需要的灰转彩、灯光和白雾继续保留。

所有插画使用 `object-fit: contain`。页面根据窗口高度分配图片、正文和控件的空间，在一屏内显示；矮横屏用左右布局，手机手记和资料可切换卡片。切页不播放整体位移、缩放或抖动。
扩展主要通过新场景和选择完成，不堆长段落，也没有新增强制等待或倒计时。中英文分支结构一致，扩展场景集中在 `story_expansion.py`，由两个构建脚本共同调用。

存档保留六个有效结局 ID，载入时清除已删除的三个结局、无效条目和重复记录。进度总数为 6，每个角色为 2。重开当前故事只重置剧情变量，不清除结局记录。

图片、十五段章节音频、三种动物叫声与两首上作配乐都使用 GitHub 原始文件直链。开始与选角播放上作的开场曲 Hollow Knight，六个最终结局与手记播放上作的收尾曲 かたわれ時。
