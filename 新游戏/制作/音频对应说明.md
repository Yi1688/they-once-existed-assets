# 音频与场景对应

## 上作配乐

| 原文件 | 标记 | 使用场景 |
| --- | --- | --- |
| audio/Hollow Knight.mp3 | `themeOpen` | 独立开始界面、选择角色 |
| audio/かたわれ時.m4a | `themeEnd` | 野猪、猫、鸭子各两个最终结局，旅程手记 |

沿用上作真实使用的开场与收尾曲，以及原仓库带内容版本号的 GitHub 原始文件直链。首页进入选角、结局进入手记时，同一首音乐继续播放。最终结局由 `scene()` 的 `ending` 标记统一选择 `themeEnd`。

## 猫与鸭子的章节音频

10 个新增 M4A 文件保留原名，上传至仓库的「新游戏」目录。`game.js` 的 `sceneAudio` 保存 GitHub 原始文件直链，`build.py` 的场景音频标记决定切换时机。

| 文件 | 标记 | 使用场景 |
| --- | --- | --- |
| 猫开场.m4a | `catOpen` | 牢笼、走道、来人、标签 |
| 猫吃药.m4a | `catInteract` | 食碗、药味、推碗、咀嚼 |
| 猫幻想.m4a | `catDream` | 世界有了色彩、新家、窗边、医院醒来 |
| 猫祭司.m4a | `catPriest` | 祭司出现并提出两个选择 |
| 猫死亡.m4a | `catEnd` | 告别阶段；最终结局改用上作收尾曲 |
| 鸭开场.m4a | `duckOpen` | 泥沼、拥挤的鸭群 |
| 鸭崇拜.m4a | `duckWorship` | 神迹、扶起同伴、获得粮食、独食或分享 |
| 鸭交互.m4a | `duckInteract` | 交替点击两只鸭子，争夺粮食 |
| 鸭天枰.m4a | `duckScales` | 天平称量与挑选 |
| 鸭祭司.m4a | `duckEnd` | 祭司提问；回答后的最终结局改用上作收尾曲 |

「鸭天枰.m4a」沿用提供的文件名；游戏中的章节标题仍为“天平”。野猪开场、交互、崇拜三个阶段继续使用原章节音频，原有「猪存活」「猪灭绝」保留在素材与音频表中，最终结局改用 `themeEnd`。

三个动物叫声继续使用 GitHub 直链，首页和选角均能点击试听。当前音频表共 20 个文件地址：十五段角色章节音频、三种叫声、两首上作配乐。

首次点击或按键后开始播放；同一文件跨页面继续，不重复从头开始。切换章节时停止上一段，回到首页或选角时切回开场曲。主题曲音量为 0.26，角色章节为 0.52，试听动物叫声时背景降到 0.12，结束后恢复。

顶部声音开关同时控制配乐、叫声试听和程序合成音效。首页的音乐按钮可解除静音；切到后台或离开页面时暂停，返回后按静音设置恢复。
