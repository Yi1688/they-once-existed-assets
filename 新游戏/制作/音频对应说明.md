# 新增音频与场景对应

10 个新增 M4A 文件保留原名，上传至仓库的「新游戏」目录。`game.js` 的 `sceneAudio` 保存 GitHub 原始文件直链，`build.py` 的场景音频标记决定切换时机。

| 文件 | 标记 | 使用场景 |
| --- | --- | --- |
| 猫开场.m4a | `catOpen` | 牢笼、同伴、关于家的承诺、标签、门外求助 |
| 猫吃药.m4a | `catInteract` | 食碗、药味、推碗、咀嚼 |
| 猫幻想.m4a | `catDream` | 世界有了色彩、新家、窗边、救助结局 |
| 猫祭司.m4a | `catPriest` | 祭司出现并提出两个选择 |
| 猫死亡.m4a | `catEnd` | 天堂、告别、两条新闻结局 |
| 鸭开场.m4a | `duckOpen` | 泥沼、拥挤的鸭群、同行结局 |
| 鸭崇拜.m4a | `duckWorship` | 神迹、扶起同伴、获得粮食、独食或分享 |
| 鸭交互.m4a | `duckInteract` | 交替点击两只鸭子，争夺粮食 |
| 鸭天枰.m4a | `duckScales` | 天平称量与挑选 |
| 鸭祭司.m4a | `duckEnd` | 祭司提问、反问、回答“是”或“否”的结局 |

「鸭天枰.m4a」沿用提供的文件名；游戏中的章节标题仍为“天平”。野猪原有五段章节音频、三个动物叫声继续使用 GitHub 直链。

首次点击后开始播放；同一文件跨页面继续，不重复从头开始。切换章节、回到选角或离开页面时停止上一段。顶部声音开关同时控制章节音频、叫声试听和程序合成音效。
