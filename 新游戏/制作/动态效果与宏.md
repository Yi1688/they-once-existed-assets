# 动态效果与 Harlowe 宏

宏直接保存在 `新游戏.twee` 与 HTML 的段落正文中，可导入 Twine 编辑。构建入口是 `build.py`；文字效果由 `enrich_scene()`、`typed_voice()`、`whisper()`、`reveal_word()`、`changing_word()` 生成，画面与音效由 `game.css`、`game.js` 补充。

逐字显示已从 7 页扩展到 37 个剧情页，另有 26 页加入可点击揭开的线索或定时变换的词句。野猪与鸭子整条路线采用黑底与浅色文字，猫整条路线采用纯白底与深色文字。路线背景去掉渐变与纹理，页眉、正文、选项、线索及结局使用同一套主题变量。插画边框根据原图比例贴合，暗场剧情的渐黑仍只发生在插画内。

可点击逐字区域覆盖了 Harlowe 默认的 `.enchantment-link` 蓝色，普通、悬停、按下和键盘聚焦均继承所在段落的文字颜色。剪影使用从原 JPG 派生的透明 PNG，原始素材保留。

## 文字

| 效果 | 使用的宏 | 场景 |
| --- | --- | --- |
| 逐字对白与结尾，点击可直接读完，完成后光标消失 | `(live:)`、`(replace:)`、`(substring:)`、`(min:)`、`(click:)`、`(stop:)` | 37 个剧情页，每页第一段纯文字对白；没有对白的结局用于收束句 |
| 点击揭开另一层含义 | `(link:)`、`(transition:)`、`(transition-time:)` | 机器的气味、幼崽蹄印、药物、被推开的碗、笼外的目光、粮食与同伴等 |
| 认知逐步改变，到最后一句停止 | `(live:)`、`(replace:)`、`(nth:)`、`(stop:)` | 完整的铁甲观察句、神明轮廓、被伐树桩、笼中的影子、糖果色栏杆、真正的家、挑选的手、属于自己的路 |
| 正文逐句显现、标题墨色掠过、可点击线索微光提示 | 保留原生宏正文，`setupTextEffects()` 仅为普通文本添加 CSS 绘制效果 | 叙述、内心话与标题，不改变段落尺寸或位置 |
| 反复倾听，三句独白循环 | `(link-rerun:)`、`(set:)`、`(if:)`、`(nth:)`、`(replace:)` | 森林、机油、关于家的承诺、鸭群里的低语 |
| 点击词语，改变理解 | `(cycling-link:)` | 不是雷霆／风声／同伴，饭里的味道，被挑选／称重／带走，天平的重量 |
| 稍后浮现新的观察 | `(after:)`、`(replace:)` | 牢笼另一端的声音、祭司看向屏幕外 |

| 标签上的“健康、活泼”被划掉 | `(after:)`、`(enchant:)`、`(text-style:)`、`(text-colour:)` | 猫观察被换掉的标签 |
| 依次读完三句话后变成普通文字 | `(seq-link:)` | 猫走向窗边 |
| 关键词的阴影、描边、模糊与明灭 | `(text-style:)`、`(text-colour:)` | 钢铁神明、逐渐昏沉的猫、喵星之门、神圣光晕 |
| 局部文字柔和显现 | `(transition:)`、`(transition-time:)` | 回声与定时独白的替换文本 |

逐字对白先用完整文本预留高度，显示中的文字放在同一位置。切词、揭示和自动变换都用最长版本预留空间；独白区固定预留两行。文字变化不会把下方选项反复推移。逐字显示每字 45ms，可点击立即读完；自动变词每段间隔 2.4 秒并包含局部显现时间。系统选择减少动态效果时，逐字对白直接显示完整内容，逐句显现、标题墨色与闪烁光标关闭。

## 画面与反馈

| 原剧本效果 | 实现 |
| --- | --- |
| 野猪第五次撞击后，机械显出神明的轮廓 | 第五次命中后预解码神明插画并更换当前画面，加一段局部亮度变化 |
| 撞击、咀嚼时的反馈 | 操作触发短促的插画位移、闪光与合成撞击／碎裂声 |
| 长按注视巨神喷气 | 三层白雾从巨神身旁向外扩散；松开暂停，进度保留 |
| 灰暗牢笼转为低饱和彩色 | 彩色场景的插画由灰阶过渡到原色，布局保持固定 |
| 温暖的家与虚幻光线 | 插画上叠加低透明度暖光呼吸，猫昏沉的词语使用模糊样式 |
| 告别时变黑，心跳与仪器提示 | 插画渐隐到黑；程序合成有限次数的心跳与仪器提示，离开场景或静音会取消后续播放 |
| 鸭子互相攻击，争得粮食 | 点击时翅膀短促摆动、亮度反馈和粮食颗粒；被淘汰的对手变暗 |
| 祭仪、光晕与钢铁神明的压迫感 | 对应场景叠加缓慢变化的紫色光晕、暖色光芒或神明显现光效 |

页面整体没有入场位移、缩放或抖动。只有玩家主动撞击、咀嚼、争食时会产生局部动作；所有导航按钮立即可用，文字效果不会强制等待。

## 选角与单屏布局

桌面选角页按窗口剩余高度分成标题、剪影、角色卡和页脚。卡片中的剪影占用剩余空间，角色名称与介绍保留可读字号，避免因为总高度略微超出就整页切换为极小字号。手机与较矮的横屏继续使用各自的紧凑布局。

剧情仍按窗口高度分配插画、文本和控件空间；全部插画使用 `object-fit: contain`，展开文字、互动完成后的继续按钮以及隐藏分支都保留单屏适配。

截图中的巨兽与蹄印段落改为完整句子的动态切换，避免替换后出现双重修饰或提前宣告结局。巨兽对白去掉重叠的阴影字样，保留逐字显示。喷气场景的正文、按钮、进度、独白及后续选择均以巨神为喷气主体。
