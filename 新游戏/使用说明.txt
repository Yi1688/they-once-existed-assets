开始游玩
双击本文件夹中的「新游戏.html」，用 Chrome 或 Edge 打开。
图片、音效、野猪的章节音频均使用本地文件；离线也可以游玩。分享时请保留整个「新游戏」文件夹，单独移动 HTML 会丢失素材。

内容
沿用旧作的三角色剪影选角与动物叫声试听。整体使用烟灰旧纸、炭灰与哑金，配色克制并保持阅读亮度；路线差异仅以细节中的冷灰、灰玫瑰与灰紫呈现。
插画边框随原图比例贴合，不再在两侧添加大块白底。三角色选角卡使用炭灰底和象牙白文字。
三条路线，九个结局。中途的观察、信任、帮助与分享会改变后续文字，以及可以选择的道路。
野猪：冷蓝色森林与钢铁巨神；五次撞击、长按喷气、观察来路与机器。
猫：低饱和的牢笼与短暂幻梦；咀嚼吞咽、观察标签与食碗、留意同伴与房间。
鸭子：高饱和的紫色祭仪；交替点击两只对手争食、分享粮食、质疑被挑选的意义。

操作
点击按钮推进剧情。有直接下一页的场景，也可以点击图片推进。
野猪撞击需要五次。长按喷气约两秒，松开后可以接着按；键盘可按住空格或回车。
鸭子争食需要交替点击左右两只鸭子，累计六次；同一只连续点击不会增加次数。
顶部「声音」同时控制配乐与音效。「选角」可重选路线。「手记」记录已抵达的结局。
页面按当前窗口高度自适应，一屏显示图片、剧情和按钮，无需滚动。调整窗口大小后会自动重新适配。
桌面选角页使用窗口剩余高度展开三张角色卡，标题、剪影和介绍文字一同放大。
带虚线的词语可以点击切换或揭开另一层含义；「再听一次」会换一句内心独白。36 个剧情页的对白或结尾逐字显示，点击文字可立即读完整句。
叙述会逐句显现，标题掠过一层墨色；26 个剧情页另有点击揭示或自动变换的线索。自动变换到最后一句后会停止，文字原位更新，按钮不用等待。
系统选择「减少动态效果」时，逐字文字直接完整显示，并关闭句子显现、标题流光与光标闪烁。
手机上的手记可点击「野猪／猫／鸭子」切换；结尾资料可点击卡片上方的主题切换阅读。
结局记录保存在当前浏览器；切换浏览器、清理站点数据或使用无痕模式会影响记录。

音频
野猪开场、交互、崇拜、存活、灭绝五段音频已按剧情切换。
选角页的三个动物叫声沿用旧作。猫、鸭目前没有章节配乐或配音，仍然可以完整游玩。
猫的牢笼画面可以点击听叫声；告别场景增加了程序合成的心跳和仪器提示音，也受顶部声音开关控制。
之后补音频时，编辑「制作/game.js」中的 sceneAudio，把猫、鸭对应的 null 换成相对路径，再重新生成即可。
声音需要第一次点击后才会播放。切换场景、返回选角或离开页面时会停止不再需要的声音。

在 Twine 中修改
可以导入「新游戏.html」，也可以使用「新游戏.twee」。故事格式是 Harlowe 3.3.9。
从 Twine 重新发布 HTML 时，请保存到本文件夹，让图片、音频的相对路径继续有效。
「制作」目录保留了构建脚本、样式、交互脚本和 Harlowe 格式文件。使用带 Pillow 的 Python 运行「制作/build.py」可重新生成 HTML 与 Twee；本机 bundled Python 已具备依赖。

剧本处理
原来的六个主要结局保留，另为三条路线各增加了一个由前面选择解锁的结局。
猫的新闻以「故事中的新闻」呈现。鸭子结尾的数据注明报告年份与来源；没有沿用“巴黎协定于 2024 年彻底失败”等不准确的表述。
新增分支与解锁条件见「制作/分支说明.md」，含剧透。
