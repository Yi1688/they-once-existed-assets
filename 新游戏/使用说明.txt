开始游玩
双击本文件夹中的「新游戏.html」，用 Chrome 或 Edge 打开。
游戏先进入独立的开始界面，点击「开始游戏」再选择角色。首页以黑白拱门、动物剪影、缓慢旋转的光环和浮尘呈现三个故事，猫在白门中，野猪与鸭子在黑门中。
图片、动物叫声、章节音频和开场、收尾配乐均通过 GitHub 原始文件直链联网读取。分享或移动时可以只复制「新游戏.html」，游玩时需要联网并能访问 GitHub 原始文件服务。

内容
沿用旧作的三角色剪影选角与动物叫声试听。野猪与鸭子的完整路线使用黑色主调、浅色文字；猫的完整路线使用纯白底、深色文字。页眉、选项、手记提示和结局随角色统一配色。
插画边框随原图比例贴合。选角与手记统一黑白：野猪、鸭子用黑底卡片，猫用白底卡片。
三条路线，每条两个结局，共六个。中途保留观察、房间探索、让路与分粮等选择，不再有找同伴和救助的第三结局。
野猪：冷蓝色森林与钢铁巨神；五次撞击、长按观察巨神喷气、观察来路与机器。
猫：低饱和的牢笼与短暂幻梦；咀嚼吞咽、观察标签与食碗、观察走道与房间。
鸭子：高饱和的紫色祭仪；交替点击两只对手争食、分享粮食、质疑被挑选的意义。

操作
点击按钮推进剧情。有直接下一页的场景，也可以点击图片推进。
野猪撞击需要五次。长按约两秒观察巨神喷出的白雾，松开后可以接着按；键盘可按住空格或回车。
鸭子争食需要交替点击左右两只鸭子，累计六次；同一只连续点击不会增加次数。
首页悬停或聚焦动物会显示它的对白，点击动物可以试听叫声。「开始游戏」进入选角，「旅程手记」查看已完成的结局；「点击开启音乐」可开启或恢复音乐。
顶部「声音」同时控制配乐与音效。「首页」返回开始界面，「选角」可重选路线，「手记」记录已抵达的结局。
页面按当前窗口高度自适应，一屏显示图片、剧情和按钮，无需滚动。调整窗口大小后会自动重新适配。
桌面选角页使用窗口剩余高度展开三张角色卡，标题、剪影和介绍文字一同放大。
带虚线的词语可以点击切换或揭开另一层含义；「再听一次」会换一句内心独白。30 个剧情页的对白或结尾逐字显示，点击文字可立即读完整句。
叙述会逐句显现，标题掠过一层墨色；24 个剧情页另有点击揭示或自动变换的线索。自动变换到最后一句后会停止，文字原位更新，按钮不用等待。
系统选择「减少动态效果」时，逐字文字直接完整显示，并关闭句子显现、标题流光、光标闪烁及首页的光环旋转与浮尘运动。
手机上的手记可点击「野猪／猫／鸭子」切换；结尾资料可点击卡片上方的主题切换阅读。
结局记录保存在当前浏览器；切换浏览器、清理站点数据或使用无痕模式会影响记录。

音频
开始界面与选角沿用上作的开场曲「Hollow Knight.mp3」，六个最终结局与旅程手记沿用上作的收尾曲「かたわれ時.m4a」。两首音乐直接使用原仓库 audio 目录的 GitHub 直链。
野猪开场、交互、崇拜，以及猫、鸭子各五段章节音频按剧情切换。野猪原有的存活、灭绝音频仍保留在素材目录和音频表中，最终结局统一使用上作收尾曲。
同一首音乐跨页面继续播放，不从头重播；进入不同章节或从结局返回首页时切换。猫在医院醒来阶段使用「猫幻想」，告别阶段使用「猫死亡」，两个最终结局均使用收尾曲。三个动物叫声沿用旧作，首页与选角均可试听。
猫的牢笼画面可以点击听叫声；告别场景增加了程序合成的心跳和仪器提示音，也受顶部声音开关控制。
之后新增或替换音频时，先将文件上传到 GitHub，再编辑「制作/game.js」中的 sceneAudio 及「制作/build.py」中的场景音频标记，然后重新生成。对应关系见「制作/音频对应说明.md」。
声音需要第一次点击或按键后才会播放。配乐切换时停止上一首，返回选角切回开场曲；页面进入后台或离开页面时暂停，回到页面后恢复。顶部声音开关保持用户的静音设置。

在 Twine 中修改
可以导入「新游戏.html」，也可以使用「新游戏.twee」。故事格式是 Harlowe 3.3.9。
从 Twine 重新发布 HTML 时，可以保存到任意文件夹；图片、音频继续通过 GitHub 直链读取。
「制作」目录保留了构建脚本、样式、交互脚本和 Harlowe 格式文件。使用带 Pillow 的 Python 运行「制作/build.py」可重新生成 HTML 与 Twee；本机 bundled Python 已具备依赖。
重新构建需要保留本地图片，以便读取尺寸和生成剪影；生成的 HTML 和 Twee 使用 GitHub 直链。新增或替换素材后，请同步上传到仓库的「新游戏」目录。

剧本处理
每个角色只保留前两个结局，猫不再两条都是死亡。载入旧存档时自动清理已删除的三个结局及重复记录。
猫的举报后续标为「故事后续」，不当作真实新闻。鸭子结尾的数据注明报告年份与来源；没有沿用“巴黎协定于 2024 年彻底失败”等不准确的表述。
分支与结局见「制作/分支说明.md」，含剧透。
原生 Harlowe 宏与动态效果的对应关系见「制作/动态效果与宏.md」。
